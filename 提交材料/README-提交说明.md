## 五、想从源码跑起来（可选）

1. HBuilderX 打开 `作品源码-v1.0.0.zip` 解压出的工程，导入 `app/`（uni-app 项目）
2. 关联**自己的**支付宝云服务空间（`app/uniCloud-alipay/`），上传全部 84 个云函数
3. 按此顺序跑一次种子函数：`school-seed` → `tag-seed` → `encyclopedia-seed` → `demo-seed` → `seed-demo-content`
   - `school-seed`：136 所学校，是学生认证与同校频道的前提
   - `demo-seed`：建三个演示账号 + 搭子关系 + 会话 + 信誉流水 + 称号
   - `seed-demo-content`：给演示账号铺 6 条搭子需求 + 6 条同频圈动态
4. 运行到手机（真机运行即可，无需打包）
