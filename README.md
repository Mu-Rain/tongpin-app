# 同频 APP（新生版）

> 一款面向大学新生的「校园搭子」匹配 App —— 帮助新生快速找到兴趣相投的伙伴（学习搭子、运动搭子、饭搭子、考研搭子等），从「陌生」到「同频」。

## 项目简介

「同频」旨在解决大一新生初入校园时「想找人一起做点什么，却不知道找谁」的痛点。用户填写兴趣、空闲时间、校区等标签后，系统在大厅中推荐合适的搭子需求，双方匹配后即可发起聊天、约伴，并在完成后通过验证后台确认履约。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | uni-app（Vue 3）+ HBuilderX，可编译到 App / 小程序 / H5 |
| 后端 | uniCloud（支付宝云）云函数 + 云数据库 |
| 用户体系 | uni-id（注册 / 登录 / 资料 / 角色） |
| 通信 | 云函数 + 轮询的消息传输层（`transport.js`） |

## 功能模块

- **用户体系**：手机号注册登录、个人资料、兴趣标签。
- **搭子大厅**：浏览 / 筛选附近的搭子需求（按兴趣、校区、时间）。
- **智能匹配**：按标签相似度与时间重叠推荐搭子。
- **即时聊天**：匹配成功后双方消息通信（云函数 + 轮询）。
- **搭子管理**：我的搭子列表、履约验证后台。

## 本地运行

1. 用 **HBuilderX** 打开 `app/` 目录。
2. 在 HBuilderX 中关联 **uniCloud 支付宝云**空间（需自行在 uniCloud 控制台创建）。
3. 上传云函数与数据库 schema（数据库集合与索引设计见 `docs/03-database.md`、`docs/08-database-indexes.md`）。
4. 运行到浏览器 / 小程序 / App 模拟器进行调试。

## 安全说明

- `set-admin` 云函数用于**一次性**初始化管理员账号，已在正式环境禁用（`ALLOW = false`）。上线前请勿在前端暴露该能力，正式管理应通过验证后台页面完成。
- 仓库已通过 `.gitignore` 排除编译产物（`unpackage/`、`dist/`）与本地密钥文件（`.env` 等），不含任何真实密钥。
