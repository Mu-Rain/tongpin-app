# 同频 APP

> 一款面向大学生的「校园搭子」匹配 App —— 帮助快速找到兴趣相投的伙伴（学习搭子、运动搭子、饭搭子、考研搭子等），从「陌生」到「同频」。

## 项目简介

「同频」旨在解决大学生在校园时「想找人一起做点什么，却不知道找谁」的痛点。用户填写兴趣、空闲时间、校区等标签后，系统在大厅中推荐合适的搭子需求，双方匹配后即可发起聊天、约伴，并在完成后通过验证后台确认履约。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | uni-app（Vue 3）+ HBuilderX，可编译到 App / 小程序 / H5 |
| 后端 | uniCloud（支付宝云）云函数 + 云数据库 |
| 用户体系 | uni-id（注册 / 登录 / 资料 / 角色） |
| 通信 | 云函数 + 轮询的消息传输层（`transport.js`） |

## 功能模块

- **用户与账号**：手机号注册登录、新生学生认证（学校验证 + 后台审核）、头像系统（内置头像库 + 裁剪）、兴趣标签、隐私设置、账号安全、黑名单。
- **搭子匹配**：大厅浏览与多维筛选（兴趣 / 校区 / 时间 / 性别）、智能推荐、搭子详情、发起约局、履约确认与搭子关系维护。
- **同频圈（社区）**：发布搭子需求与图文动态、点赞 / 评论 / 收藏、举报与审核闭环、浏览足迹。
- **即时聊天**：文字 / 图片 / 语音消息、撤回、搜索、清理会话、会话设置、好友申请、**AI 情绪提示**（按「连续短句」「深夜时段」两条规则触发，只做陪伴提示，不作诊断）。
- **信用与称号**：信用分流水（加分 / 扣分与原因）、称号体系（获取 / 佩戴）、校园百科（词条浏览 + 每日一读）。
- **管理后台**：用户管理、举报审核、称号管理、百科内容管理。

## 10 分钟极速复现指南

> 本指南满足传智杯「AI 创新应用挑战赛」对 **README 复现性声明** 的硬性要求：环境配置、依赖清单、环境变量模板齐全，评委可在约 10 分钟内把项目跑起来。

### 环境与依赖清单

| 工具 | 版本要求 | 用途 |
| --- | --- | --- |
| **HBuilderX（App 开发版）** | 最新稳定版 | uni-app 开发 / 运行 / 云打包（唯一必需 IDE） |
| **DCloud 账号** | 免费 | 关联 uniCloud 服务空间、云打包 |
| **uniCloud 支付宝云** 免费服务空间 | — | 云函数 + 云数据库后端（在 HBuilderX 内一键开通） |
| 安卓手机（或模拟器） | Android 9+ | 真机运行 / 调试（也可直接运行到浏览器） |
| Node.js | ≥ 16 | 仅用于本地跑 `_verify_crypto.js` 单元测试（可选） |

> 本项目**不依赖** npm 安装第三方包；uni-app 运行所需依赖由 HBuilderX 内置，无需 `npm install`。

### 复现步骤

1. **打开工程**：用 HBuilderX 打开本仓库的 `app/` 目录（顶层 `dazi-app/` 含 `docs/`、`prototype/`，但工程根在 `app/`）。
2. **开通云服务**：右键 `app/uniCloud-alipay` →「创建/关联云服务空间」→ 选 **支付宝云**（免费）→ 关联。此时 `hello` 云函数即可运行。
3. **创建数据库**：按 `docs/03-database.md` 的集合字段表与 `docs/08-database-indexes.md` 的索引清单，在 uniCloud 控制台建集合与索引（或上传 DB Schema）。
4. **上传云函数**：右键 `app/uniCloud-alipay/cloudfunctions/` 下每个函数 →「上传部署」（一次性全选上传也可）。
5. **灌基础数据（seed）**：`tag-seed` / `school-seed` 直接运行即可（灌标签与学校，幂等）。`card-seed` / `fit-seed` / `demo-seed` / `seed-demo-content` 这几个**会造出演示账号与演示内容**，正式环境默认 `ALLOW=false`，本地复现时先把文件顶部的 `const ALLOW = false` 改成 `true` → 重新部署 → 运行一次 → **立刻改回 `false`**。
6. **运行**：`app/manifest.json` 已含 `appid`；点「运行 → 运行到手机或模拟器 / 运行到浏览器」即可看到登录页并真机注册登录。

### 环境变量 / 密钥模板

本项目**不含任何真实密钥**，也不强制要求环境变量即可跑通主链。若后续接入 AI 能力（如聊天机器人），按项目规范（`docs/05-plan-and-ai-workflow.md` §4）**只**把密钥写在云函数的「运行环境配置」里：

```
# 云函数运行环境配置（uniCloud 控制台填写，切勿写进代码或提交 Git）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx   # 仅聊天机器人模块需要；本期版本未实际调用
```

仓库内 `.gitignore` 已排除 `.env` / `.env.*` / `*.key`；**所有一次性运维 / 灌数据云函数在正式环境默认 `ALLOW=false`**（`set-admin`、`migrate-pairkey`、`set-verify-school`、`card-seed`、`fit-seed`、`demo-seed`、`clean-seed-data`、`seed-demo-content`、`uid-backfill`），代码库中不存在硬编码密码、密钥或真实手机号。
