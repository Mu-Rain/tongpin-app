# 同频 · 高保真 HTML 原型（新粗野主义）

双击 `index.html` 就能打开（`file://` 直接可用，不需要起服务器、不需要联网）。
手机上打开最真实；在电脑上建议窗口宽度 390px 左右（F12 → 手机模拟）——不过**效果图总览**是桌面宽度下最好看的一页。

## 两种看法

顶部有两个视图按钮：

- **可点击原型**：手机壳里真的能点，带过渡动画
- **效果图总览**：一页铺开全部 15 屏缩略图（430×880 设计稿 0.4× 等比缩放，带状态栏与顶栏），点任意一张直接跳进那一屏

顶部还有一排「直达」按钮（15 个），任意一屏一键到达，当前那一屏会反色高亮。

## 怎么点

- 底部 4 个标签：首页 / 同频圈 / 消息 / 我的 —— 黑块会滑过去，不是瞬切
  中间还有一个**抖音式凸起的橙色「＋」**（凸出栏外、悬停会转 90°），点它直接进「发一条日常」
  （**进大厅、学习、健身、详情、匹配、认证、称号、聊天、发日常、我的搭子这些二级页后，底部导航栏会收起**）
- 首页：便当格布局，尺寸刻意不统一 —— 搭子大厅最大（唯一主入口）→ 学习 与 健身 等大 → 心理疏导（虚线占位卡）→ 每日百科细条
- 搭子大厅：**顶部就是「发布搭子需求 ＋」入口**（原来悬在右下角的发布按钮已取消）→ 筛选 chips（含「竞赛」）+「同校 / 附近 / 城市」段控件 → 点卡片进详情 → 点「我想搭」
- 同频圈：**三栏 同校 / 地区 / 发现**（发现 = 全国）+ 图文 / 视频 / 吐槽筛选 + 静态卡片流；底部「＋ 发一条日常」进发帖页
- 发日常（占位页）：可见范围、正文、图文 / 视频 / 纯文字、三个上传位、话题标签 → 点发布只弹提示
- 消息 → 底部「我的搭子与标签」：**自定义搭子标签编辑器** —— 标签框（限 8 字）+「＋搭子」按钮、8 个推荐词、8 个预设**闪亮色**、实时预览；列表里点「改标签」可把某段关系的标签载入编辑
- 聊天：输入框敲字回车或点发送，900ms 后会有对方回复（假数据，本地演示）
- 我的：学生认证 / 称号库 / 健身与打卡 / 学习与番茄钟 → 四个二级页
- 健身页：7 个格子点一下就能打卡（本地记账，不联网）
- 学习页：番茄钟 25:00，开始 / 暂停 / 继续 / 重置，进度条跟着走
- 称号库：12 个称号（3 个已获得），普通 / 稀有 / 传说三档
- 顶栏按钮会从底部弹出抽屉（发布、每日百科）

## 搭子标签的闪亮色

预设 8 色，全部带「反光质感」——底色之外再叠一道斜向白色高光：

| key | 名称 | hex |
| --- | --- | --- |
| shine-yellow | 闪耀黄 | `#ffde00` |
| shine-orange | 熔岩橙 | `#ff4d00` |
| shine-rose | 荧光粉 | `#ff5fa2` |
| shine-violet | 霓虹紫 | `#a855f7` |
| shine-cyan | 电光青 | `#22d3ee` |
| shine-mint | 薄荷绿 | `#34d399` |
| shine-blue | 宝石蓝 | `#3b82f6` |
| shine-gold | 香槟金 | `#e9c46a` |

实现：`.tag--buddy` / `.color-dot` / `.buddy-tag--big` 用内联 `background-color` 打底 + CSS `background-image` 的 115° 白色渐变做高光；悬停卡片时标签还会有一道反光扫过（`@keyframes shine`）。

## 设计规范（新粗野主义）

| 项 | 值 |
| --- | --- |
| 边框 | `3px solid #000`，直角（圆角 = 0） |
| 阴影 | 硬阴影，无模糊：`4px 4px 0 #000` / 悬停 `8px 8px 0 #000` |
| 主原色 | 黄 `#ffde00`、橙 `#ff4d00`（标签调色板是例外，见上一节） |
| 按钮 | 悬停向左上位移 2px，按下向右下压 3px 且阴影归零 |
| 数字 | 等宽字体 + `tabular-nums`，避免跳动 |

动效时长都收在 `style.css` 顶部的变量里（`--dur-fast: 160ms` / `--dur: 240ms` / `--dur-slow: 320ms`，缓动 `--ease: cubic-bezier(.22,1,.36,1)`），想统一调快调慢只改这三行。

分段控件的列数由 `--seg-count` 控制（HTML 里内联写 2 或 3）——写死 `repeat(3, 1fr)` 会让两个按钮的行多出一个空列，这是之前的一个 bug。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 15 个屏的静态结构 + 两个底部抽屉 + 顶部直达按钮 + 效果图总览容器 |
| `style.css` | 全部样式与设计变量（改颜色只改顶部 `:root`） |
| `app.js` | 屏幕切换、列表渲染、标签编辑器、效果图总览生成、番茄钟、打卡、开关（普通 script，不用 ES module，所以 `file://` 能跑） |
| `build.mjs` | 把 css / js 内联进 html，生成单文件版；改完源文件跑一次 `node build.mjs` |
| `同频原型.html` | **单文件版（生成物，别手改）**：样式和脚本都内联在里面，一个文件就能发到手机 / 微信 / 别的电脑上直接打开 |

## 已知限制（别当成 bug）

- 全是假数据：登录不发请求、聊天没有后端、匹配结果是写死的标签重合度
- 没做真机 / 无头浏览器截图验证（本机沙箱不让无头 Chromium 起渲染进程），视觉以你自己打开为准
- 抽屉、卡片、聊天气泡都只演示交互，不保存状态；刷新即回到初始
- 「发日常」页只占字段与流程：不上传、不审核、不入库
- 标签编辑器点「＋搭子」只是把第一段关系的标签改掉，模拟"保存成功"，不落库

## 改文案 / 改颜色

- 文案：直接在 `index.html` 里搜中文改
- 颜色：`style.css` 顶部 `:root` 的 `--yellow` / `--orange` / `--ink` / `--paper`
- 标签闪亮色：`app.js` 顶部的 `TAG_COLORS` 数组
