## 0. 用户原话

> 「我打包之后发现一个新问题，**每日百科那看不到往前内容**；**点击卡片不能跳转到百科推送界面**，可以设计一个百科页面」

## 2. 要做的

### 2.1 云函数 `encyclopedia-list`（新建）

**入参**：`{ page?=1, page_size?=20 }`（`page_size` 上限 50）
**不需要 token** —— 和 `encyclopedia-daily` 一样，未登录也能看百科。

**出参**：
```json
{ "code":0, "data": {
  "list": [ { "_id":"…", "title":"…", "category":"study",
              "publish_date":"2026-10-23", "summary":"前 60 字…",
              "created_at": 1760000000000 } ],
  "total": 20, "page": 1, "page_size": 20, "has_more": false } }
```

**规则**：
- 只查 `active: true`，**软删的（`active:false`）不出现**（`admin-encyclopedia` 的 remove 是软删）
- 排序：`publish_date` 倒序，其次 `created_at` 倒序（与 `encyclopedia-daily` 的回落口径一致）
- **列表不下发全文**，只给 `summary`（取 `content` 前 60 字 + `…`）。理由：20 条 × 150 字 = 3000 字，一次全下发在小程序上会明显卡顿
- 表不存在 → 返回 `{list: [], total: 0}`，**不报错**

### 2.2 云函数 `encyclopedia-detail`（新建）

**入参**：`{ id }`
**出参**：`{ code:0, data: { item: { _id, title, content, category, publish_date, created_at } } }`

- 找不到 / 已软删 → `404`「这篇百科已经下线了」
- 表不存在 → 404（不是 500，因为「没有这条」是合法结果）

### 2.3 页面 `pages/encyclopedia/encyclopedia.vue`（列表）

- 顶部：「每日百科」
- 每条：标题、分类小标、日期、摘要（最多两行）
- 第一条（今天的或最近的）加一个「今日」标记
- 触底加载更多（`has_more` 为真时）
- 四态：加载中 / 空（「还没有百科内容」）/ 出错 / 正常
- 点某条 → 跳详情

### 2.4 页面 `pages/encyclopedia/detail.vue`（详情）

- 标题、分类、日期、全文
- 底部：`‹ 上一篇` / `下一篇 ›`（可选，若做需要 `encyclopedia-detail` 额外返回相邻 id，**本轮可不做**）
- 四态同上

> 路由用 `pages/encyclopedia/encyclopedia` 和 `pages/encyclopedia/detail` 两个目录也可以，注意 `pages.json` 路径要和文件一致。

### 2.5 首页卡片可点

`pages/index/index.vue` 的百科卡（`:58` 那个 `<view class="card">`）加 `@tap`，跳列表页。

**注意**：现在卡片里有「展开/收起」按钮（`:80`），它自己也有 `@tap`。给整卡加 `@tap` 会冲突——要么：
- 方案 A：整卡可点跳列表，「展开」按钮用 `@tap.stop` 阻止冒泡
- 方案 B：只在卡片右上角加一个「全部 ›」

**推荐 A**（用户说「点击卡片不能跳转」= 期望整卡可点）。

## 3. 铁律

1. `.vue` 模板不许用 `<script>` 顶层 const，先 `data()` 注册。
2. 云函数业务错误走 `code`；表不存在静默降级；**这两个函数都不要 token**（未登录也能看百科）。
3. 云函数目录自包含（只有 `index.js` + `package.json`），不许跨目录 `require`。
4. 改完 `node --check`。
5. 注释只写「为什么」，全中文。
6. **不许动** `encyclopedia-daily` / `encyclopedia-seed` / `admin-encyclopedia`（都已验收）。
7. `pages.json` 加路由，**tabBar 4 项不动**。

## 4. 验收

| 项 | 标准 |
|---|---|
| 首页卡片 | 点整卡 → 跳列表页；点「展开」→ 只展开，**不跳页** |
| 列表页 | 显示 20 条；日期倒序；每条只显示摘要 |
| 触底 | `has_more` 为假时不显示「加载更多」 |
| 详情页 | 全文完整；软删的条目返回 404 并给友好提示 |
| 未登录 | 列表和详情都能看（不要求 token） |
| 后台联动 | 管理员在 `admin-encyclopedia` 停用一条 → 列表页刷新后它消失 |
