> 给「前端 UI 设计」会话用：**哪些页面还没按新设计体系重做过**，以及每个页面具体差在哪。
> 判断依据是代码里的客观事实（是否用 design tokens、圆角/字号是否收敛、裸写色值多少），不是主观印象。

## 一、判据（怎么算「已重设计」）

新体系的两个特征：

1. **颜色走 tokens**：`var(--tf-primary)`、`var(--tf-text)`、`var(--tf-card)`、`var(--tf-r-lg)` 等，定义在 `app/App.vue` 的 `page { ... }` 里。
2. **圆角与字号收敛**：圆角不超过 3~4 种、字号不超过 6 种；卡片统一 `--tf-r-lg`，整轮胶囊用 `999rpx`。

一条辅助信号：裸写十六进制色值（`#1F5CAC` 一类）越多，说明这个页面还停在旧体系。

统计口径：`tokens` = 文件里 `var(--tf-` 的出现次数；`裸色` = `<style>` 里 `#RRGGBB` 的数量。

## 四、改的时候必须守的规矩（否则会返工）

1. **颜色只能用 tokens**：`--tf-primary`、`--tf-text`（主文字）、`--tf-text-2`、`--tf-text-3`、`--tf-card`、`--tf-bg`、`--tf-line`；圆角用 `--tf-r-sm` / `--tf-r-md` / `--tf-r-lg` / `--tf-r-xl`（**没有 `--tf-r-pill`**，胶囊直接写 `999rpx`）。页面里不要再出现新的 `#RRGGBB`。
2. **禁用语法**：`?.`、`??`、`.at()` 一律不许用（低版本安卓 webview 不支持，项目全程禁）。
3. **头像**：加载失败只显示空圆，**绝对不要**渲染 `/static/avatar-default.png` 或任何默认图。
4. **改中文文件用 node + 锚点断言**：`s.split(old).length - 1 === 1` 断言唯一后再写盘，不要用编辑器的替换功能。
5. **CRLF 保持**：多数 `.vue` 是 CRLF，写入前 `split('\r\n').join('\n')`，写完还原。`app/pages/mine/mine.vue` 是 LF，别当损坏。
6. **页面别加 `<svg>`、`filter: url()`、mask**：App 端渲染成本高，项目约定不用。
7. **自定义 tabBar**：`tabBar.custom = true`，真条在 `app/custom-tab-bar/index.vue`，改导航样式改那里，不要改 `pages.json` 的 tabBar 文案（不生效）。
8. **动效时长引用变量**：只有三个 —— `--dur-micro`、`--dur-page`、`--dur-enter`（**没有 `--dur-fast`/`--dur-base`**）。`prefers-reduced-motion` 已有兜底。

## 五、建议的施工顺序

1. 登录 + 注册（**用户第一眼看到的两个页面，收益最大**）：先把裸色逐个映射到 tokens，再把字号收敛到 `52/35/28/24` 四档，圆角统一 `--tf-r-lg`。
2. 我的动态、称号：圆角与字号收敛为主，结构不动。
3. 设置、头像系统、百科详情：补卡片层级（`--tf-card` + 轻阴影）、统一圆角。

## 六、验收自查（每页改完都跑）

- 页面 `<style>` 里 `#RRGGBB` 数量为 **0**（启动图除外）。
- 圆角种类 ≤ 4、字号种类 ≤ 6。
- 无 `?.` `??` `.at(`。
- 深浅色都看一遍（项目有主题变量，切换后不能有硬编码色漏出）。
- 空态、加载态、错误态三态都在。
- 长昵称、超长标题不撑破卡片（`word-break: break-all` 或 `text-overflow`）。
