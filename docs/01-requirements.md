## 1. 一页纸定义

- **一句话**：帮大学生在 3 分钟内找到一个"今天就能一起做一件事"的同校 / 同城同学。
- **目标用户**：全国在校大学生（大专 / 本科 / 研究生），以 18–25 岁为主，手机号注册。
  - **学校范围（阶段性收窄，不是永久）**：本期 `school-seed` 只收录**高等院校**（专科 / 本科 / 研究生），不收录中小学。理由：中小学生接触手机时间少，用户量会很低，先不做。
  - ⚠️ **后续规划：中小学以后肯定要加入**。所以数据模型里 `schools` 表保留 `level` 字段（`college` / `middle` / `primary`），代码中**不要写死"只有大学能用"的判断**；将来扩范围 = 往 `schools` 表补数据 + 认证材料按学段分支（中小学没有学信网，只能走学生证），不需要改表结构。
- **核心痛点**：想自习、健身、拍照、吃饭、跑步，缺一个伴；现有陌生人社交平台太重、目的不纯、不安全。
- **差异化（答辩就讲这 4 条）**：
  1. **搭子 ≠ 好友**：搭子是"一起做一件事"的轻关系，带**自定义标签**（限 8 字，可从 8 个闪亮预设色里挑颜色，**像备注一样只有自己看得见**）；想升级才成为好友，也可退回。
  2. **标签重合度匹配**：不刷信息流。填 8–10 个标签（作息 / 强度 / 性格 / 兴趣 / 偏好），按加权重合度排序推荐。
  3. **信誉分 + 稀有称号**：守约、完成搭子加分，放鸽子、被举报扣分；称号从互动中获取且稀有——把"靠谱"量化。
  4. **AI 只做轻介入**：独立聊天框的情绪引导机器人（= 首页「心理疏导」，本期只保留入口与占位，见 §2.6）+ 组队破冰建议；明确不做心理诊断。
- **核心闭环**：注册 → 完善资料与标签 → 选需求 → 发布 / 浏览卡片 → 匹配 → 私聊 → 建立搭子关系 → 完成互评 → 信誉分 / 称号。

## 3. 角色与权限

| 角色 | 获得方式 | 能做 / 不能做 |
|---|---|---|
| 游客 | 未登录 | 只能看登录页 |
| 未认证用户 | 注册即得 | 可发卡片、可聊天、浏览大厅公开区；**不能**进同校频道、不能匹配同校 |
| 认证用户 | 认证审核通过 | 进入同校频道；卡片带认证标识；匹配权重更高 |
| 搭子 | 双方建立搭子关系 | 有独立聊天栏 + 搭子标签；**不自动**成为好友 |
| 好友 | 任一方发起、对方同意 | 可互相看到资料卡、可直接发起私聊 |
| 低信誉用户 | 信誉分 < 60 | 不能发卡片、不能进同校频道，只能被浏览 |
| 管理员 | 后台账号 | 认证审核、举报处理、封禁、百科与称号配置 |

### 4.12 2026-10-18 定案（搭子标签 = 私有备注）

用户原话：「我觉得可以删掉"你叫他\*\*\*""他叫你\*\*\*"，自己只能看到自己给对面起的搭子标签，就类似于备注一样，但是不要与用户备注混为一谈」。

| 编号 | 内容 | 验收标准 | 优先级 |
|---|---|---|---|
| US-52 | 作为用户，我只看得到**我自己**给对方起的搭子标签 | ① 「我的搭子」页、消息列表、聊天页顶部、个人主页一律只显示**我这一侧**的标签；② 界面上不再出现「你叫他 / 他叫你」这类对照展示；③ 对方改标签不会让我这边变化 | P0-1 |
| US-53 | 作为用户，我不能替对方起名，对方也不能替我起名 | ① 任何入口（同意卡片申请 / 接受定向邀请 / 主动改标签）都**只写自己那一侧**；② 接受邀请时只让**接受方**给**自己**起名，不把发起方写的名字抄给我 | P0-1 |
| US-54 | 作为用户，我要能分清「搭子标签」和「用户备注」 | ① 搭子标签绑**一段关系**（同一对人在「学习」「夜跑」两段关系下可以各有各的标签），用户备注绑**一个人**；② 两者字段、存储、生命周期互相独立，**不合并、不互相覆盖** | P0-1 |

> **实现落点**：`buddy_relations.label_a` 只属于 `user_a`、`label_b` 只属于 `user_b`；`buddy-list` / `user-profile` / `buddy-invite` / `message-conversations` 四个云函数均已停止下发对方那一侧。设计说明见 `03-database.md` §2.3 的「私有备注」告示。
>
> **为什么不做「互相可见」**：初期设计是双方各看一眼对方的叫法，但那样等于替对方定称呼——我起的名字会出现在对方屏幕上，而对方无从选择。改成私有备注后，标签退化成纯粹的个人索引工具（像通讯录备注），既保留了"一句话认出这个人"的便利，也不会因为别人给我起的名字尴尬或产生误会。
