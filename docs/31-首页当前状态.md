## 二、关键参数（app/pages/index/index.vue 顶部常量）

| 常量 | 值 | 含义 |
|---|---|---|
| `HERO_MAX` | 300 | 头图展开高度 px |
| `HERO_MIN` | 64 | 头图压缩后高度 px |
| `HERO_RANGE` | 180 | 滚动多少 px 完成压缩 |
| `CARD_H` | 400 | 单卡高度 rpx |
| `STACK_GAP` | 64 | 堆叠时每张露出的高度 rpx |
| `OPEN_GAP` | 416 | 展开后行距 rpx |

**约束**：`padding-top(76rpx) > STACK_GAP(64rpx)`，否则堆叠会露出下一张卡的内容。

## 三、滚动联动（onPageScroll）

一个进度 `p = clamp(scrollTop / 180)` 同时驱动：

- `heroH = 300 - 236 * p`
- `heroMin = p > 0.92`
- `deckP = p`（卡片展开用同一个进度）
- `idOpacity = max(0, 1 - p * 2)`

**三个过渡都加了**（这是平滑的关键，删掉任何一个都会抖）：

```css
.hero { transition: height 120ms linear }
.deck { transition: height 120ms linear }
.deal { transition: transform 120ms linear }
```

## 四、卡片堆的位置插值

```js
const stackTop = uni.upx2px(STACK_GAP * (n - 1 - i))  // 起点：底部锚定
const openTop  = uni.upx2px(OPEN_GAP * i)              // 终点：顶部排列
const top = stackTop + (openTop - stackTop) * p
const scale = 1 - (1 - p) * i * 0.022                  // 后面的卡缩小
zIndex = n - i                                          // 第 0 张最前
```
