## 5. 关键契约（改之前必须知道）

### 5.1 云函数入参出参

前端只通过 `uniCloud.callFunction` 调云函数，返回体统一 `{ code, msg, data }`，`code === 0` 才是成功。

| 云函数 | 关键入参 | 关键出参 |
|---|---|---|
| `card-list` | `token` / `type` / `scope`（`school` 默认 \| `city` \| `nearby`）/ `page` / `page_size` | `data.list` / `has_more` / `total` / `matched_total` / `degraded` |
| `card-detail` | `token` / `card_id` | `pending_count` **仅发布者可见**，非发布者拿不到 |
| `message-send` | `token` / `conversation_id` / `type` / `content` / `meta` | `data.message_id` / `meta` |
| `meetup-confirm` | `token` / `message_id` / `action`（`accept` \| `decline`） | `data.status` / `data.both` |
| `track-event` | `event` / `props` / `token`（可空） | 一律 `code: 0`，未登录降级匿名 |

### 5.2 三个必须记住的字段口径

1. **`matched_total` 的 0 与 null 是两件事**：`0` 是「真的没有同频」，`null` 是「算不出来」（未登录、无标签、候选超 2000 张）。前端必须分开显示，不要把 `null` 当 `0`。
2. **`degraded` 与 `reason` 不是一回事**：`degraded` 取值 `''` / `'no_city'` / `'nearby_as_school'` / `'no_location'`，是「降级说明」；`reason` 只在 `no_school` 早退分支出现。别混用。
3. **`owner` 一定存在**：`card-list` 服务端会兜底补 `owner`（含 `nickname` / `is_verified` / `school` / `credit_score`），前端不用判空。

### 5.3 埋点

唯一入口 `utils/track.js`：**不返回 Promise**（调用方无从 await）、整体 try/catch + `.catch()` 双层兜底、同 `event|JSON.stringify(props)` 2 秒内去重、token 从 `uni.getStorageSync('token')` 取（取不到就空串，服务端降级匿名）。

**禁止**把埋点写成会阻塞 UI 的写法，也**禁止**在循环里对同一张卡重复上报。

## 7. 环境与工具坑（省你半小时）

### 7.1 怎么校验 .vue 语法

`node` 不认识 `<template>`，必须把 `<script>` 段抽出来单独 check：

```js
// 存成 _chk.mjs 放工作区根目录跑，跑完删掉
const fs = require("fs"), os = require("os");
const p = "路径/xxx.vue";
const t = fs.readFileSync(p, "utf8");
const s = t.indexOf("<script"), e = t.indexOf("</script>");
fs.writeFileSync(os.tmpdir() + "\\_chk.mjs", t.slice(t.indexOf(">", s) + 1, e), "utf8");
```

然后 `node --check %TEMP%\_chk.mjs`，看退出码。

**用 PowerShell 跑，不要用「程序里起子进程捕获输出」的写法** —— 该环境会 `EPERM`。

### 7.2 怎么扫「模板 class 有没有对应样式」

```js
const tmpl = t.slice(t.indexOf("<template>"), t.indexOf("</template>"));
const style = t.slice(t.indexOf("<style"), t.lastIndexOf("</style>"));
const cls = new Set();
for (const m of tmpl.matchAll(/(?<![:\w-])class="([^"]+)"/g))
  m[1].split(/\s+/).forEach(c => c && cls.add(c));
const defined = new Set();
for (const m of style.matchAll(/\.([A-Za-z_][\w-]*)/g)) defined.add(m[1]);
console.log([...cls].filter(c => !defined.has(c)));
```

注意 `(?<![:\w-])` 这个负向断言不能去：去掉之后 `:class="{...}"` 里的表达式会被误当成 class 名，报一堆假缺口。

### 7.3 四个已知的环境问题

| 问题 | 现象 | 对策 |
|---|---|---|
| `tools.edit` 偶发写不进去 | `ReplaceFileW EIO (Win32 1175)` | 改用「读全文 → 字符串替换并断言命中 1 次 → 写回全文」，一次搞定 |
| 中文乱码 | PowerShell 默认编码不是 UTF-8 | 读写显式指定 UTF-8 |
| 子进程 EPERM | 程序内调 `execFileSync('node', ...)` 被沙箱拒绝 | 改用 PowerShell 跑 `node` |
| `flag` 写成 `#ifdef DEBUG` | uni-app 只认平台名，**伪代码** | 开发/发行用 `process.env.NODE_ENV !== 'production'` |
