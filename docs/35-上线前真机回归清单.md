## 十二、红了怎么查（按现象给排查入口）

| 现象 | 先查什么 |
| --- | --- |
| 头图/启动图空白 | `unpackage/dist/dev/app-plus/static/` 对应文件是否 0 字节；改图后是否重编译过 |
| 数字不对（同频/需求/搭子） | 对应云函数是否上传新版本：`card-list` / `home-summary` / `buddy-list` |
| 卡片没有档位标签 | `card-list` 没上传（前端只兜全站，不算档位） |
| 头像全是默认图 | `user-me` 是否上传（它负责把 cloud:// 换成 https 临时链接） |
| 观看历史一直空 | `browse_history` 集合是否建了；`browse-record` 是否上传 |
| 分享面板没有搭子 | `buddy-list` 是否上传（面板要它返回 other_user_id 与 conversation_id） |
| 推送收不到 | 基座是否勾 uni-push 2.0；`push_tokens` 有没有记录；`push-send/package.json` 的 extensions 是否含 `uni-cloud-push` |
| 点通知没反应 | `message-send` 是否上传（payload 里要有 conversation_id） |
| 上拉更早没反应 | `message-list` 是否上传（要支持 beforeMessageId） |
