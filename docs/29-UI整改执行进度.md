### 聊天气泡：恢复第一套的实心偏移 ⚠️（对文档 §2.3 的一处例外）

**背景**：UI 整改按文档 §2.3 把全局 `--tf-lift` 从实心偏移改成了柔和弥散投影，
聊天气泡因为用 `var(--tf-lift)`，厚度感一起没了 —— 气泡变成「飘」在页面上。

**处理**：**不动全局**，在 `chat.vue` 的 `.chat-wrap` 里定义一组局部变量：

```css
--bub-lift:  4rpx 4rpx 0 rgba(45, 42, 38, 0.42);   /* 气泡 / 图片 */
--bub-line:  rgba(45, 42, 38, 0.30);               /* 配套暗描边 */
```

**为什么这是合理的例外**：

| | 卡片 | 气泡 |
|---|---|---|
| 隐喻 | 信息块，贴在地上 | **纸片浮在页面上** |
| 投影 | 柔和弥散（§2.3 正确） | **实心偏移，不加模糊** |
| 原因 | 模糊能营造「轻」 | 模糊会把边缘糊掉，读不出厚度 |

文档 §2.3 的 `$shadow-card` 是给**卡片**定的，气泡不属于这个范畴。

**同时恢复的**：
- 对方气泡底：纯白 → **暖白渐变**（`白 0.92 → 极淡橙 0.72`），保留第一套「有色彩倾向、能透背景」的质感
- 自己气泡末端色：`#16457F`（靛蓝残留）→ `var(--tf-primary-deep)`
- 图片气泡、图片占位：同步恢复实心偏移

对比预览：`聊天气泡-恢复实心偏移.png`
