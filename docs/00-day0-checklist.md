# 第 0 天实操清单：装 HBuilderX + 建 uniCloud 空间

> 目标（就是今天）：**真机上点一下按钮 → 看到「✓ 连通成功」**。
> 做完这一步，M0 就完成了；后面所有功能都建立在这条链路上。
>
> 预计 40–60 分钟。中间任何一步报错，把**完整报错文字/截图**发我，别自己猜。

---

## 你现在要准备的

| 事项 | 说明 |
| --- | --- |
| DCloud 账号 | 手机号注册即可，免费。HBuilderX 第一次启动会让你登录 |
| 安卓手机 | 打开「开发者选项 → USB 调试」，用数据线连电脑 |
| 电脑 | Windows，16G 内存（够用）；**不需要**装 Node、Java、Android Studio、Docker |

## 第 1 步：装 HBuilderX（约 15 分钟）

1. 打开 <https://www.dcloud.io/hbuilderx.html>
2. 下载 **App 开发版**（不是标准版，标准版没有真机运行的完整能力），选 **Windows 版**
3. 解压后直接运行 `HBuilderX.exe`（**绿色软件，不用安装**，放哪都行）
4. 首次启动会提示登录 DCloud 账号 —— 用手机号注册并登录

> 判断装对没：菜单栏能看到 `运行` 和 `发行` 两个菜单，且 `运行 → 运行到手机或模拟器` 是可点的。

---

## 第 1.5 步：设置 AppID（必做，否则点运行会报错）

第一次点「运行」时如果弹出 **「缺少appid，请在manifest.json中设置appid」**，按下面做：

1. 在左侧项目管理器里**双击** `manifest.json`（必须用 HBuilderX 自带的编辑器打开，不要用记事本）
2. 点顶部标签栏最左边的 **「基础配置」**
3. 找到第一行 **AppID**，点右边的蓝色按钮 **「重新获取」**
   - 会自动填成 `__UNI__` 开头的一串
   - **如果按钮是灰的**：说明 HBuilderX 没登录 DCloud 账号 → 点右上角头像登录（手机号注册，免费）
4. 按 `Ctrl+S` 保存

> 这一步只做一次。AppID 绑定你的 DCloud 账号，是云打包和真机运行的必需项。

---

## 第 2 步：打开工程（约 2 分钟）

1. `文件 → 打开目录`
2. 选中这个文件夹：

```
C:\Users\lenov\Documents\deepseek-harness\default-workspace\dazi-app\app
```

> **注意**：选 `app` 这一层，不要选 `dazi-app`。选错了 HBuilderX 会认不出项目。

选对的话，左侧项目管理器里会出现 `pages`、`uniCloud-alipay`、`App.vue`、`main.js`、`manifest.json` 这些节点。

---

## 第 3 步：先跑通界面（约 10 分钟）

1. 手机插上电脑（USB 调试已打开）
2. 点击顶部菜单 `运行 → 运行到手机或模拟器 → 你的手机型号`
3. **第一次会很慢（5–10 分钟）**：HBuilderX 要下载「调试基座」安装到手机上，这是正常的，不是卡死

预期结果：手机上出现「同频」登录页 —— 顶部大字「同频」、下面手机号 / 密码两个输入框、一个橙色「登录」按钮。

> 看不到手机设备？依次检查：① 手机屏幕是否弹了「允许 USB 调试」并有勾选"始终允许"；② 换一根能传数据的数据线（有些线只能充电）；③ 手机上装了华为/小米助手类的拦截软件会挡，先退出。

---

## 第 4 步：建 uniCloud 服务空间（约 10 分钟）

1. 在左侧项目管理器里找到 `uniCloud-alipay` 目录 → **右键** → `关联云服务空间或项目`
2. 弹窗里点 `新建` → 服务空间名称填 `tongpin-dev`（随便起）→ 服务商选 **支付宝云** → 有「免费版」就选免费版
3. 建好后选中它，点 `关联`
4. 关联成功后，`uniCloud-alipay` 目录图标会变（通常带个云朵标记），右键里也会多出 `上传所有云函数` 之类的菜单

> **为什么是支付宝云（2026-10-16 改）**：DCloud 官方公告，**阿里云服务空间自 2026 年 11 月 1 日起不再支持新建**，并将于 **2027 年 9 月 30 日正式停服**。所以阿里云这条路**已经堵死**，不是"能不能用"的问题，是"根本建不了"。
>
> 支付宝云是当下唯一"免费 + 可新建"的选项（腾讯云没有免费版，最低 99 元/月）。它和阿里云一样：1 个免费空间、云函数 / 云数据库 / 云存储 / uni-push 全套。
>
> **两个注意点**：① 支付宝云要求 DCloud 账号的**实名认证信息**与你名下的**支付宝账号完全一致**（个人对个人、企业对企企业）；② 支付宝云 2026 年 3 月 25 日之后新建的内置数据库**已切回标准 MongoDB**，早些年"数组/布尔/数值字段必须建索引才能查"的坑已不存在，本文档的写法可以直接用。
>
> 免费版额度以官网为准，做演示和几十人内测够用。**别嫌它慢，它替你省掉了买服务器 + 备案的 1–3 周。**

---

## 第 5 步：部署第一个云函数（约 5 分钟）

项目里已经放好了一个测试用云函数，路径：

```
dazi-app\app\uniCloud-alipay\cloudfunctions\hello
```

1. 右键 `hello` 这个目录（或右键其 `index.js`）→ `上传部署`
2. 等待提示「上传成功」

> 如果右键没有「上传部署」：说明第 4 步的服务空间没关联成功，回去重做第 4 步。
>
> 如果提示「请先关联服务空间」，同理。

---

## 第 6 步：真机点按钮，验收（约 2 分钟）

1. 手机上打开刚跑起来的「同频」App（如果它停在登录页，随便进首页即可 —— 首页就有测试按钮）
2. 找到 **「测试云函数连通性」** 按钮，点它
3. 预期看到：

```
✓ 连通成功：hello from uniCloud｜服务空间 你的spaceId
```

> 如果你想确认到底连的是哪家云，把 `hello` 云函数的 `index.js` 里 `provider` 字段一起打出来即可 —— 支付宝云会是 `alipay`。首页那个按钮目前只显示 `spaceId`，够用。

**看到这行字，今天的任务就完成了。** 这条链路 = 手机 App → 云函数 → 返回，是后面聊天、匹配、AI 全部功能的地基。

> **如果之前已经跑过（手机上残留旧版本）**：换服务商后必须让 HBuilderX **重新编译**，否则跑的还是旧的阿里云产物。做法：菜单 `运行 → 运行到手机或模拟器` 之前，先 `发行 → 原生 App 云打包` 不用管，直接删掉项目里的 `unpackage` 目录再重新运行即可（我已帮你删过一次）。

## 出错了怎么排查（按顺序试）

| 现象 | 最可能的原因 | 怎么办 |
| --- | --- | --- |
| 点按钮显示「当前平台用不了 uniCloud」 | 你在**浏览器**里打开，不是手机 | 改用 `运行 → 运行到手机或模拟器`；H5 端要额外配跨域代理，先不折腾 |
| 点按钮报 `Space is not found` / `spaceId` 相关 | 服务空间没关联，或关联错了 | 重做第 4 步；确认 `uniCloud-alipay` 目录已带云朵标记 |
| 建空间时提示「认证失败，请确认名称和证件号码是否已注册支付宝账号」 | DCloud 实名主体与支付宝账号主体不一致 | 个人号要用**同名**的个人支付宝；企业号要用**同名**的企业支付宝（不能用法人个人的）。名下如有多个支付宝账号，先注销没用的再试 |
| 报 `Function not found` / `hello 不存在` | 云函数没上传成功 | 重做第 5 步，确认提示「上传成功」 |
| 报网络相关错误 | 手机没网 / 校园网拦截 | 换 4G 或热点再点一次 |
| HBuilderX 里看不到手机 | USB 调试没开 / 线不对 | 见第 3 步的三个检查点 |
| `运行` 菜单是灰的 | 下载的是标准版 | 换 App 开发版重下 |
| 右侧项目管理器里**根本没有** `uniCloud-alipay` 目录 | 项目目录打开了旧的，或用了 `uniCloud-aliyun` 的旧副本 | 确认打开的是 `dazi-app\app`；若模型里还叫 `uniCloud-aliyun`，说明你打开的是旧版本，重新 `文件 → 打开目录` |
