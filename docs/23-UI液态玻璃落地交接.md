## 1. ⚠️ 开工前必读：三个硬约束

这三条如果判断错，会造成大面积返工。先花五分钟读完。

### 1.1 底部导航现在是**原生 tabBar**，做不了玻璃滑块

`app/pages.json` 用的是原生 `tabBar`：

```json
"tabBar": {
  "color": "#8F959E", "selectedColor": "#FF6B4A", "backgroundColor": "#FFFFFF",
  "list": [ {"pagePath":"pages/index/index", …}, … ]
}
```

原生 tabBar 由系统绘制，**跑不进 CSS**。效果图里那个「凸出栏外、会滑动、带折射的玻璃胶囊」，在原生 tabBar 上做不到。

**必须先改成自定义 tabBar**，见 §5.2。这是本次实装里**工作量最大、风险最高**的一块，建议单独做一个里程碑。

### 1.2 折射（SVG 位移图）在 uni-app 里不可移植

效果图的边缘折射依赖：

```
feImage(位移图) → feDisplacementMap → filter: url(#lensWarp)
```

这套在浏览器里成立，但在 uni-app 有明确限制：

| 端 | `filter: url()` 引用 SVG | `backdrop-filter` |
| --- | --- | --- |
| H5 | ✅ | ✅ |
| App（webview） | ⚠️ 不稳，部分机型直接失效 | ✅ Android 10+ / iOS 9+ |
| App（nvue） | ❌ | ❌ |
| 小程序 | ❌ | ⚠️ 仅部分基础库 |

**结论：折射不做移植，只保留 `backdrop-filter`。**
「大半径模糊 + 高饱和 + 10% 白底 + 1px 白边 + 内侧厚度高光」这五条全部能在 `backdrop-filter` 上实现，视觉完成度约 85%，只有边缘那一点弯折没有。

> 如果确实要折射，唯一可行路径是 H5 端加，App 端降级。不要为了它把三端搞裂。

### 1.3 单位换算：px → rpx **必须**换算，不能照抄

效果图按 390px 宽设计；uni-app 里 `750rpx = 屏幕宽`。

```
rpx = px × (750 / 390) = px × 1.923
```

| 效果图 px | uni-app rpx | 用途 |
| --- | --- | --- |
| 1 | 2 | 边框 |
| 11 | 22 | 极小字 / 角标 |
| 13.5 | 26 | 正文 |
| 15.5 | 30 | 卡片标题 |
| 26 | 50 | 页面大标题 |
| 20 | 40 | 圆角·中 |
| 26 | 50 | 圆角·大 |
| 32 | 62 | 圆角·超大（页面主卡） |
| 62 | 120 | tabbar 高度 |

**照抄 px 会让整个界面缩到三分之一。**

### 4.2 页面底色（替换 `page{}` 里的 `background-color`）

**注意**：uni-app 的 `page{}` 支持多背景渐变，但 `radial-gradient` 在部分安卓 webview 上有性能开销。这里用四角光斑 + 线性渐变，实测无卡顿。

```css
page {
  background-color: #EEF4F6;
  background-image:
    radial-gradient(120% 90% at 6% -12%, #F8FCFB 0%, rgba(248,252,251,0) 64%),
    radial-gradient(95% 72% at 97% -8%,  #D9E9F4 0%, rgba(217,233,244,0) 60%),
    radial-gradient(92% 74% at 94% 106%, #C9DDC4 0%, rgba(201,221,196,0) 64%),
    radial-gradient(88% 68% at -8% 104%, #D3E5EE 0%, rgba(211,229,238,0) 62%),
    linear-gradient(178deg, #F9FCFB 0%, #E9F2F3 48%, #DDE8EF 100%);
  background-attachment: fixed;   /* 关键：不跟着滚动跑 */
}
```

### 4.3 玻璃卡公共类（放 `App.vue` 的 `<style>` 里，全站可用）

```css
.tf-glass {
  background-color: var(--tf-card);
  border: 2rpx solid var(--tf-line);
  border-radius: var(--tf-r-lg);
  box-shadow: var(--tf-glass-shadow);
  backdrop-filter: var(--tf-glass-blur);
  -webkit-backdrop-filter: var(--tf-glass-blur);
}
```

> **`border: 2rpx` 不是 1rpx**。rpx 在 390 宽的机型上 2rpx ≈ 1px；写 1rpx 在部分安卓上会渲染成半个像素，变成灰色的虚线。

## 6. 自定义 tabBar 实现要点

### 6.1 必须知道的三件事

1. **改原生 → 自定义**：`pages.json` 的 `tabBar` 加 `"custom": true`，然后建 `app/custom-tab-bar/index.vue`。
2. **页面切 tab 用 `uni.switchTab`**，不是 `navigateTo`。
3. **每个 tab 页都要在 `onShow` 里同步高亮**，否则切页后滑块不动：

```js
onShow() {
  if (typeof this.$mp?.page !== 'undefined' && this.$mp.page.getTabBar) {
    this.$mp.page.getTabBar().setData({ selected: 0 })  // 第几个 tab
  }
}
```

### 6.2 结构（照抄效果图的三层分离）

```html
<view class="tf-tabbar-slot">
  <view class="tf-tabbar-tray"></view>     <!-- ① 底槽玻璃，柔边 -->
  <view class="tf-lens" :style="{ transform: `translateX(${i * step}px)` }">
  </view>                                   <!-- ② 滑块玻璃，亮边，凸出栏外 -->
  <view class="tf-tabbar">
    <view v-for="(t,i) in tabs" :key="i" class="tf-tab" :class="{ 'is-on': selected === i }"
          @tap="go(i)"> … </view>
  </view>                                   <!-- ③ 仅文字层，无背景 -->
</view>
```

**为什么必须三层分开**：`backdrop-filter` 会创建新的层叠上下文。如果文字层和底槽在同一个元素里，文字再高的 `z-index` 也压不过滑块 —— 效果图阶段实际踩过这个坑，文字被玻璃盖住了。

### 6.3 关键样式

```css
.tf-tabbar-slot { position: fixed; left: 32rpx; right: 32rpx; bottom: 42rpx; height: 120rpx; z-index: 99; }

.tf-tabbar-tray {
  position: absolute; inset: 0; border-radius: 46rpx;
  background-color: rgba(255,255,255,0.12);
  backdrop-filter: blur(26px) saturate(1.9) brightness(1.04);
  border: 2rpx solid rgba(255,255,255,0.42);
}

.tf-lens {
  position: absolute; left: 0; top: -10rpx; height: 140rpx; width: 25%;
  border-radius: 56rpx;   /* 按高度比例放大，见下方说明 */
  background-color: rgba(255,255,255,0.11);
  backdrop-filter: blur(22px) saturate(1.95) brightness(1.06);
  border: 2rpx solid rgba(255,255,255,0.92);
  box-shadow: 0 10rpx 24rpx rgba(31,92,172,0.20),
              inset 0 3rpx 0 rgba(255,255,255,1),
              inset 0 -3rpx 0 rgba(255,255,255,0.5);
  transition: transform 520ms cubic-bezier(0.34, 1.56, 0.64, 1);
}

.tf-tabbar { position: absolute; inset: 0; display: flex; align-items: center; z-index: 3; }
.tf-tab { flex: 1; position: relative; z-index: 3; }
```

**圆角必须按高度比例算**。设底槽高 `H1`、半径 `R1`，滑块高 `H2`，则：

```
R2 = R1 × (H2 / H1)
```

按本方案 `H1 = 120rpx, R1 = 46rpx`（比例 0.383）、`H2 = 140rpx`，得 `R2 = 46 × 140 / 120 ≈ 54rpx`。

> 照抄同一个圆角数值会让两条弧线交叉，在角落露出一条「复边」。效果图阶段为此调了三轮才定位到原因是**曲率**而不是位置。

### 6.4 位移量要实测，不能写死

```js
// tab 宽随屏宽变化，写死百分比换设备就错位
measure() {
  uni.createSelectorQuery().in(this).select('.tf-tab').boundingClientRect(r => {
    this.step = r.width
  }).exec()
}
```

### 6.5 降级开关（重要）

自定义 tabBar 在低端机上有风险：`backdrop-filter` + 固定定位 + 过渡动画三者叠加，可能掉帧。

**给它一个一键降级**：

```js
// App.vue onLaunch 里判断
const lowEnd = uni.getSystemInfoSync().platform === 'android'
  && uni.getSystemInfoSync().system?.indexOf('Android 1') === 0   // Android 10 以下
if (lowEnd) uni.setStorageSync('tf_glass_off', 1)
```

CSS 里：

```css
.tf-glass, .tf-tabbar-tray, .tf-lens { backdrop-filter: none; -webkit-backdrop-filter: none; }
.tf-glass { background-color: rgba(255,255,255,0.92); }   /* 退化成半透明实心 */
```

退化后视觉仍在，只是没有模糊。

## 7. 已知坑（效果图阶段踩过的，别重复踩）

| # | 坑 | 现象 | 解法 |
| --- | --- | --- | --- |
| 1 | `backdrop-filter` 与 `mask` 同用 | 遮罩被完全忽略 | 遮罩挂到外层 `filter` 上，不挂 `backdrop-filter` 那层 |
| 2 | `backdrop-filter` 不支持 `url()` 滤镜 | 写了折射但毫无效果 | 折射在 uni-app 里**放弃**（见 §1.2） |
| 3 | `backdrop-filter` 创建层叠上下文 | 文字被玻璃盖住，z-index 失效 | 文字单独成层，不在玻璃元素内部 |
| 4 | 大半径模糊会抹平折射 | 边缘弯折看不见 | 分区：中心重模糊、边缘轻模糊（uni-app 可省略） |
| 5 | 两个相邻玻璃元素白边同亮度 | 看起来像「画错了」 | 一强一弱：容器柔边、子元素亮边 |
| 6 | 圆角照抄数值 | 角落露出一条复边 | 按高度比例算（§6.3） |
| 7 | px 直接写进 rpx 语境 | 界面缩到三分之一 | 乘 1.923（§1.3） |
| 8 | `background-attachment: fixed` 忘写 | 渐变跟着内容滚，露出白底 | 务必写上 |
| 9 | 组件里写 `<style scoped>` 但用全局类 | `.tf-glass` 不生效 | 公共类放 `App.vue` 的非 scoped `<style>` |
