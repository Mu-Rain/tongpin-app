### 2.3 关键口径（别改）

- 模型来源优先序：用户自己的配置 → `ai_config/_id='default'` → 环境变量 `AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL`。三级都没有返回 `code 501`。
- 配额：默认模型 30 次/天（`DEFAULT_DAILY`），自带 key 300 次/天（`SELF_DAILY`）；**只有成功才计数**。
- key 只看得到掩码：用户 key 回前 3 + 后 4，默认 key 连尾号都不回。
- SSRF：`isPrivateHost()` 拦 localhost / 127. / 10. / 192.168. / 172.16-31 / 169.254。
- 生成需求卡：标签字典（按 `weight` 排序，封顶 `TAG_PROMPT_LIMIT=96`）塞进 prompt，模型只能从里面挑，回来由服务端换 id；认不出的进 `tags_unknown` 只给前端看，**不入库**。
- 找搭子：模型只出意图 `{types,tags,keywords,time,note}`，服务端召回最近 200 张 open 卡打分（共同标签 ×4 / 关键词 ×3 / 类型 ×2 / 24h 内 +1.5），取前 6 条，每条带 `reason`；全不命中给 `fallback` 的最近 6 条。
- AI 的结果**不进大厅列表**：大厅的分页游标与滚动位置绑在 `card-list` 上，混进去就退不回来，所以 AI 是独立页。

### 4.1 这次踩过的坑（别再踩）

- `node` 里调 `execFileSync(node, ...)` 会 **EPERM**（沙箱禁 spawn + 管道 stdio）→ 校验脚本只能「node 写文件 + pwsh 循环 `node --check`」。
- 正则 `<text[^>]*/>` 会把 `<textarea … />` 当成自闭合 `text`，造成假的标签不平衡；判断配平要用 `<text(?=[\s>])` + 深度扫描。
- 改中文文件用 `edit` 偶发 `ReplaceFileW EIO` → 一律用 `node:fs` + 锚点唯一性断言（`s.split(old).length - 1 === 1`），多行锚点要按 `\r?\n` 匹配。
- 删整段临时代码必须按**方法边界**定位：上一次按「空行」截断，把 `index.vue` 的 `onPageScroll()` 一起删了，还把 `onReady()` 塞进了 `methods`。
- 桌面目录（`C:/Users/lenov/Desktop/传智杯提交文件`）在工作区外：`pwsh` 必须带 `sandbox_permissions: 'danger-full-access'`，`node:fs` 读它会 ENOENT。
