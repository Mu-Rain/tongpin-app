## 2. 灌数据（这一步不做，动作库是空的）

右键 `fit-seed` → **上传并运行**。

返回里应该有这几行：

```json
{
  "code": 0,
  "msg": "灌数据完成（重复运行安全）",
  "data": {
    "exercises": { "inserted": 66, "skipped": 0 },
    "plans": { "inserted": 5, "skipped": 0, "items_inserted": 49, "items_skipped": 0 }
  }

```

**再跑一次应该变成 inserted=0 / skipped=66**，这是幂等设计，重复跑不会重复写。

如果第一次就返回 `inserted: 0, skipped: 66`，说明之前跑过，没问题。

## 4. 验收清单

### 4.1 健身首页
- [ ] 顶部三个数字：本周训练 / 连续天数 / 本月打卡
- [ ] 「今天练什么」下面有 **5 套计划**（推拉腿三分化、上下肢二分化、全身新手、减脂循环、拉伸恢复）
- [ ] 每套计划显示「每周 N 练 · N 个训练日 · N 个动作」
- [ ] 下面有日历，今天那格有圈

### 4.2 动作库
- [ ] 点「动作库」进去，默认列出全部 66 个动作
- [ ] 顶部肌群栏：胸 / 背 / 肩 / 二头 / 三头 / 腿 / 臀 / 核心 / 前臂 / 小腿 / 有氧 / 拉伸，每个带数字角标
- [ ] 点「胸」只剩胸部动作；再点一次取消
- [ ] 器械栏点「哑铃」只剩哑铃动作
- [ ] 搜索「卧推」能搜到 4 个左右的卧推类动作（防抖 350ms，打字停下才请求）
- [ ] 点开任意动作，弹层显示肌群/器械/具体部位/难度/协同肌群 + 建议组次 + 要点

### 4.3 训练主链（最关键）
- [ ] 首页点「自由训练」或点某套计划 → 进训练页
- [ ] 带计划进来的话，「今天的动作」已经按训练日自动填好
- [ ] 重量填 20、次数填 10 → 点「记一组」→ 下面出现「1 · 20 kg × 10」
- [ ] 再记一组 25kg × 8 → 出现第二组
- [ ] 如果这动作以前没记过重量 → 应该弹 **🏆 新纪录！**（第一次练都算 PR）
- [ ] 点右上「＋ 加动作」→ 能搜动作加进来
- [ ] 组数 > 0 时，动作块右上角「移除」会提示「已经记了组，删不了」（防止误删）
- [ ] 每组的 ✕ 可以删（会二次确认）
- [ ] 点「结束训练」→ 二次确认 → 弹「训练完成 + 组数/容量/用时」

### 4.4 训练记录
- [ ] 练完回到健身首页，本周训练 +1、日历今天亮起来
- [ ] 首页「📓 训练记录 · 查看历史 ›」点进去，能看到刚才那次
- [ ] 点一条记录，弹层按动作分组列出每一组的重量 × 次数，破纪录的那组带 `PR`

### 4.5 番茄钟（本轮已返工：自定义时长 + 离开页面继续计时）
- [ ] 首页点「学习」→ 进番茄钟
- [ ] 选 15 分 → 点「开始专注」→ 秒数开始倒数
- [ ] 「暂停」能停住，「继续」接着走
- [ ] 点「放弃」→ 确认 → 如果超过 1 分钟会记一条未完成（完成率会下降）
- [ ] 让一个 15 分的跑完（可以先改成 1 分钟验证，但云函数最少 1 分钟）→ 弹「🍅 完成一个番茄」→ 手机上应该震动
- [ ] 本周柱状图今天那根变橙、数字 +15

**返工后新增的两条，重点验：**

- [ ] **自定义时长**：点最右边「自定义」→ 输入框出现 → 填 3 → 点开始 → 从 03:00 倒数。
      填 0 / 181 / 空 → 下方出现红字「填 1 - 180 的整数」，点开始会提示、不会开始。
- [ ] **离开页面继续计时**（这次返工的核心）：
      1. 设 3 分钟 → 开始 → 看到 02:5x
      2. **切到别的页 / 按 Home 键退到后台**，等 1 分钟
      3. 回到学习页 → 剩余时间应该是 **01:5x 左右**（不是重新从 03:00 开始）
      4. 再试「杀掉 App 重新进」→ 同样应该接着走，不是归零
      5. 暂停后切走再回来 → 剩余时间**不变**（暂停期间不该走表）
      6. 让它在你**不在页面时**跑到 0 → 回页面应弹「🍅 完成一个番茄」，且
         `study_pomodoros` 里那条的 `minutes` 是你选的时长，不会少记

## 6. 报错对照表

| 报错 / 现象 | 原因 | 怎么办 |
|---|---|---|
| `不认识的动作：xxx` | 云函数没重新部署，还是旧版 | 重新上传部署 |
| `未登录` / `登录已过期` | token 失效 | 我的 → 退出登录 → 重新登录 |
| 动作库空的、肌群角标全是 0 | 没跑 `fit-seed` | 见第 2 步 |
| 计划列表空的 | 同上 | 同上 |
| `这个动作不存在` | 灌数据时被跳过 | 重跑 fit-seed |
| 记一组报 `次数要在 1 - 200 之间` | 次数没填或填 0 | 填个正整数 |
| 记一组报 `重量要在 0 - 500 公斤之间` | 重量填太大 | 正常训练不会超过 |
| 番茄钟点开始没反应 | 页面在 `onShow` 里刷统计，注意别在有弹窗时点 | 重进页面 |
| 训练页一进去就返回 | `start` 报错了，看控制台 | 看第 5 节的集合有没有建出来 |
| 编译报 `"default" is not exported` | `labels.js` 必须用 `export` 不是 `module.exports` | 本项目已经写成 export default，别手改 |

## 8. 本轮的技术债（下次动手前先看）

| 债 | 影响 | 什么时候要还 |
|---|---|---|
| 休息计时器没做 | 记完一组不会自动倒计时 | 训记的核心功能之一，排在下一轮 |
| 容量曲线 / PR 榜 / 部位分布没做 | 数据都在库里，只是没页面 | 数据已按可扩展设计存好，加页面即可 |
| `fit_sets` 一次训练上限 500 组、同动作 20 组 | 正常训练远够 | 够用，别急着改 |
| 加载训练页时会连发 3 个请求（start + detail + plan） | 首次进稍慢约 0.5 秒 | 以后可以合并成一个 `fit-session action=enter` |
| ~~番茄钟切到后台靠系统计时，可能不准~~ | **已修**（本轮返工） | 改成「开始时刻 + 累计时长」推算，息屏 / 切页面 / 重启都不漂 |
| 训练页「用上次的重量」只取本次上一组 | 跨天同动作不会自动带出上次的重量 | 下一轮加一个 `fit-session action=lastSets` 一次查最近记录 |
