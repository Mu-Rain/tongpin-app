## 五、打包前必须改的两行

`app/manifest.json` 现在是：

```json
"versionName": "0.1.0.0.1",
"versionCode": 101
```

**这个值从项目开始到现在没动过。** 真机装了新包但表现没变时，第一件事就是查这两行——覆盖安装的判断依据是 `versionCode`。

建议改成：

```json
"versionName": "0.2.0",
"versionCode": 102
```

`versionCode` 必须是整数且**严格递增**，不能回退。

## 七、打包流程（HBuilderX）

1. 改 `manifest.json` 的 `versionName` / `versionCode`（见 §五）
2. 菜单「发行 → 原生 App 云打包」
3. 平台选 Android，证书选「使用公共测试证书」（仅演示）/ 或自己的证书
4. 打包类型选「正式版」（**不要选「安心打包」之外的调试变体**）
5. 等云打包完成，控制台会给一个 APK 下载链接，同时 HBuilderX 会打开输出目录
6. 手机上**卸载旧包再装**（首次换证书必须卸载；同一证书可直接覆盖）

## 十、出问题时的排查顺序

| 现象 | 先查这里 |
|---|---|
| 首页空 | `card-list` 传了吗；控制台手动跑 `{"type":"all"}` 看 `data.list` |
| 登录后闪回登录页 | token key 是不是 `'token'`（全项目四处 setStorageSync 都用这个名） |
| 点星标报错 | `card_favorites` 集合建了吗 |
| 约局确认点了没反应 | `meetups` 集合 + `meetup-confirm` 传了吗 |
| 埋点表里一条都没有 | `track_events` 集合建了吗；`track-event` 传了吗（它失败是静默的） |
| 装了新包但什么都没变 | `versionCode` 没加，覆盖安装被系统当成同一个包 |
| 顶部有大片留白 | 三个 tab 页要 `navigationStyle: custom` + `padding-top: calc(var(--status-bar-height) + 16rpx)` |
